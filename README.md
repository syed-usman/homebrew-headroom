# Homebrew Tap for Headroom

Official Homebrew tap for [Headroom](https://github.com/syed-usman/headroom) — native APFS disk forensics & space reclaimer for macOS.

## Installation

```bash
brew install --cask syed-usman/headroom/headroom
```

Or tap first:

```bash
brew tap syed-usman/headroom
brew install --cask headroom
```
